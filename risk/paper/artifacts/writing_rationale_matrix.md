# Writing Rationale Matrix

| Manuscript choice | Rationale |
|---|---|
| One-column IEEE draft | The user requested no page limit and full data display; one-column mode keeps long evidence tables readable while preserving IEEEtran. |
| Separate formal, addendum, and external evidence | Prevents over-claiming from mixed protocols. |
| Show risk-only as degenerate | Zero cost with near-zero route completion is not safety. |
| Do not declare gated-risk superiority | Formal and external evidence do not support that stronger claim. |
| Include all inventory artifacts | Documents the full `/home/aaa/data/qj` scope without pretending every file is an experiment result. |
