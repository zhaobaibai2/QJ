# Official Formatting and Scope Notes Used on 2026-07-01

Sources checked:
- IJMLC homepage: https://link.springer.com/journal/13042
- IJMLC aims and scope: https://link.springer.com/journal/13042/aims-and-scope
- IJMLC submission guidelines: https://link.springer.com/journal/13042/submission-guidelines
- Springer Nature LaTeX author support: https://www.springernature.com/gp/authors/campaigns/latex-author-support

Applied decisions:
- IJMLC scope includes machine learning and cybernetics, including control of system-environment interactions.
- Manuscript uses a cybernetic feedback narrative instead of an IEEE short-paper framing.
- Springer Nature journal article template package was downloaded from the official author-support page.
- `sn-mathphys-ay` is used for author-year/name-year citation style.
- Data availability and code availability statements are included because Springer guidelines require a data availability statement for original research articles.
- Figures are copied to the same level as `main.tex`, following Springer LaTeX upload guidance.
